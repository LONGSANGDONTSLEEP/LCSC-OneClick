# 通过可版本化元件模型连接数据源与导出器

官方 JSON 先转换为具有明确电气与几何语义的 IR，AD 和 KiCad 导出器读取同一个模型。这样新增 EDA 适配器时可以复用解析与校验，并保留不同目标软件需要的信息。IR 使用毫米、局部原点、Y 轴向上及逆时针角度；原始数据、外观策略、目标格式限制分别处理。

IR 从 1.0 开始定义序列化协议。新增可选字段必须有保持旧行为的默认值，未知可选字段与命名空间扩展在读写时保留；需要新语义的文档必须声明 required_features，旧导出器拒绝未知必要能力。破坏性语义变更必须升级主版本并显式迁移，不能通过修改同名字段含义绕过版本检查。各导出器按目标版本声明支持范围，并拒绝无法准确表达的关键电气或制造图元。

第一版保留现有 AD 导出、合并和追加行为；KiCad 支持新建符号和封装库。KiCad 已有库追加、工程库注册及 3D 自动放置独立实施，模型下载保持原始文件。
