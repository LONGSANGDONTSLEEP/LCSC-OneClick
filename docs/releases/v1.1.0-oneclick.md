# 立创一键导出 1.1.0 · PCB 库整合 3D

下载 Windows 便携 ZIP，解压运行 `LCSC-OneClick.exe`。重新导出器件即可得到包含 3D 的库。

- AD：STEP 自动内嵌进 PcbLib，封装写入原生 3D Body 与模型 GUID，无需手动添加 STEP。
- KiCad：封装自动关联 STEP；将 `OneClick_3D` 复制到你的 KiCad 工程根目录即可。
- 自动转换源库的原点偏移、旋转与高度；回读并逐字节校验嵌入的 STEP。
- 没有模型、不支持的放置参数、共享封装存在不同3D关联等情况明确报告，保留二维库。

保留 BOM 导入、AD + KiCad 六种格式一键导出、ZIP、结果清单和失败重试。

导出的是元件库，不含整板工程。生产前须在 EDA 3D 视图核对位置与尺寸。本次未在 Altium Designer 桌面软件中人工验收。
