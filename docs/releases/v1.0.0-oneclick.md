# 立创一键导出 1.0.0

下载 `LCSC-OneClick-Windows-x64.zip`，解压后双击 `LCSC-OneClick.exe`。

- 粘贴 C 编号 / BOM / 含 C 编号的链接，自动提取与去重。
- 一键导出 AD + KiCad 符号与封装、STEP / OBJ。
- 唯一任务目录、自动 ZIP、CSV 和 JSON 结果清单、失败重试。
- 保留高级商城、收藏、模型与符号封装预览。

基于 Travelerrrrrr/LCSC3D 2.3.0，AGPL-3.0-or-later。完整源代码在 `LCSC-OneClick-Source.zip` 中。

导出元件库，不含整板工程。3D 需手动绑定和校准；缺失官方模型会报告部分完成。

本地在线验证：C2040 和 C20197 均成功导出六种格式。完整回归和 EXE 冒烟测试结果见 `VALIDATION.txt`；校验值见 `SHA256SUMS.txt`。
