# LCSC3D 2.3.0：KiCad 导出与统一 EDA 中间层

本版新增 KiCad 符号与封装导出，并引入统一的 EDA 中间层，让同一份官方元件数据用于 AD 和 KiCad。下载 Windows 便携程序即可使用，无须安装 Python 或外部转换工具。

## KiCad 导出

- 在 **导出到** 中选择 **KiCad**，生成 KiCad 8+ 的 `.kicad_sym` 符号库和 `.pretty` 封装库。
- 符号与封装可独立导出、分别合并和命名，也可保留每个器件的单独副本；共享封装自动复用。
- 引脚电气类型默认跟随源数据，可统一指定，不支持的类型设为“未指定”。
- 符号预览采用 KiCad 风格；矩形使用直角和实心主体背景填充。

## 中间层与导出器

官方 JSON 先转换为版本化中间层，集中保存引脚电气类型与方向、多单元符号、图形文字、焊盘、孔与过孔等信息，再由 AD / KiCad 导出器生成对应文件。兼容规则保留旧数据与既有字段含义，为后续支持其他 EDA 提供基础。

## 修复与体验改进

- 修正部分符号的引脚方向，预览与实际导出同步修复；旧版导出的异常符号需重新导出。
- 支持 C31966 等封装中的过孔：AD 保留原生过孔，KiCad 以无编号镀通孔保留位置、孔径和铜环。
- 修复长结果文字重叠、底部控制栏间距和切换“合并”时的闪动。
- 搜索与收藏增加商品缩略图，搜索每页 20 项并保留跨页勾选。
- AD 追加支持自定义工程输出目录、库名和按钮直接导入工程，改进文件选择界面。
- 完善 AD / KiCad 导出、文件替换和失败恢复日志，验证日志打包、清除后续写与崩溃记录。

## 使用提示

**AD / KiCad 普通导出与再次合并会覆盖同名库，以本次勾选为准。** KiCad 替换整个同名 `.pretty` 目录，旧成员会移除；需要保留的器件请一并勾选。AD 的“追加”模式继续保留原库成员，KiCad 暂不支持追加。

在 KiCad 库管理器中添加库时，封装库昵称须与导出库名一致。KiCad 封装过孔的网络归属需要在 PCB 中确认。两种目标均暂不自动绑定 3D 模型；KiCad 暂不支持工程自动注册。

下载 `LCSC3D.exe` 直接运行，或在 **设置 → 关于与支持 → 检查更新** 中升级。`LCSC3D.zip` 为完整源码，`SHA256SUMS.txt` 为校验文件。
