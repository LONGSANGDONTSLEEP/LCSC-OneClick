# 2.3.0-demo.1：KiCad 元件库导出第一版

本地开发版本，开发分支为 `codex/functional-demo`；未发布 GitHub Release。

- 官方 JSON 先转换为可版本化的 EDA IR，AD 与 KiCad 从同一模型导出。支持未知可选字段保留、必要能力检查和源图元扩展，为其他 EDA 适配预留边界。
- 增加 KiCad 符号、封装和合并库选项；支持多单元、复杂焊盘、偏心铜、槽孔及共享封装引用。
- KiCad 首版新建库，不覆盖已有同名库；失败或取消时撤回本次未被外部修改的文件。AD 原有独立、合并、追加及工程引用继续可用。
- KiCad 默认使用原生字体和配色、Passive 引脚；曲线按目标能力离散，器件外形投影层按装配轮廓显示，相关转换在结果与日志中提示。
- 尚未支持 KiCad 已有库追加、工程库自动注册、封装 3D 自动绑定。APP 预览仍显示官方资源，不是 KiCad 文件渲染。

库注册方法见 [使用说明](../../app/README.md)，架构与扩展规则见 [EDA 中间层](../EDA中间层.md)，验证证据见 [本版验证记录](../2.3.0-demo.1验证记录.md)。
