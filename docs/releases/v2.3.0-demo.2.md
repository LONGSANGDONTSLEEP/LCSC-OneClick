# 2.3.0-demo.2：KiCad 导出配置与预览

本地功能分支 `codex/functional-demo`，接续 2.3.0-demo.1。

- 工作台新增“导出到”下拉框，选择 Altium Designer 或 KiCad，显示对应的配置项。STEP/OBJ 两种目标均可选。隐藏配置不会参与本次导出，切回目标恢复之前的选择。
- IR 保留每个引脚的电气类型、未知类型值与原始来源代码；旧数据缺失该字段时采用未指定。
- KiCad 默认跟随源类型，可选择具体类型统一覆盖本次导出的全部引脚。支持全部 12 个 KiCad 类型，不支持或无法确定方向的类型回退为未指定。覆盖不会修改 IR，也不会改变 AD 的既有 Passive 策略。
- 矩形及圆角矩形轮廓统一采用实心、主体背景颜色填充。
- “合并符号库”和“合并封装库”独立控制。可只合并封装到一个 `.pretty` 目录，或只合并符号；共享封装复用，符号引用保持一致。旧“合并 KiCad 库”配置迁移为两项同时启用。
- KiCad 目标的符号预览固定为 KiCad 风格，隐藏嘉立创/AD 样式选择；切回 AD 恢复原风格。

预览在官方 SVG 上应用样式，字体排版与 KiCad 原生渲染可能不同。当前继续只新建 KiCad 库；暂不追加已有库、自动注册工程库或自动关联 3D。

本地最新入口：`outputs/LCSC3D.exe`。本版源码包、说明和校验和同步保存在 `outputs/` 与 `outputs/v2.3.0-demo.2/`。未推送或发布线上 Release。
