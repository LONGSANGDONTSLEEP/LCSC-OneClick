# 2.3.0-demo.4：封装过孔、合并闪动与日志补齐

本地功能分支 `codex/functional-demo`，接续 2.3.0-demo.3。

- 修复 C31966（TPS54560DDAR）等封装中 VIA 图元导致 AD/KiCad 封装导出失败的问题。9 个焊盘和 4 个过孔完整保留：AD 使用原生 VIA，KiCad 使用无编号镀通孔并提示转换规则。孔径、铜环和位置独立核对；不会擅自分配引脚编号。
- IR 更新为 1.1，独立表示过孔及跨层范围，继续读取原 1.0 文档。未知图元显示具体来源类型，必要能力由目标显式声明，后续适配器不会默默丢弃孔。
- 修复点击“合并”时先绘制压缩布局、随后滚动区域再次调整导致的闪动。尺寸调整在绘制前完成，包含 KiCad 嵌套选项与滚动条宽度变化。
- 审查并补齐日志：KiCad 转换失败、逐格式结果、合并模式、文件替换和回滚均可追踪；结构化错误保留器件、格式、阶段、图元类型及原因链。日志打包与清理继续使用明确白名单，清理后日志写入及崩溃捕获可用。

同名库仍按本次选择整体覆盖；AD 的追加行为不变。已有失败导出的 C31966 封装需要重新导出。

固定入口 `outputs/LCSC3D.exe`；EXE、源码 ZIP、使用说明和校验和同步到 `outputs/` 与 `outputs/v2.3.0-demo.4/`。本地提交，不推送、不打标签、不发布线上 Release。
