# 2.3.0-demo.3：引脚方向、布局与重复合并修复

本地功能分支 `codex/functional-demo`，接续 2.3.0-demo.2。

- 修复 C5879483 等符号的引脚反向：来源路径可以从本体画向连接端，导入器现在依据电气连接点识别两端，不再依赖绘制顺序。AD/KiCad 实际导出和 AD 风格的向外延长预览同步修复；此前受影响的库需要重新导出。
- 修复下载结果长文字与表格重叠、底部控制栏紧贴上方区域。布局随文字换行、列宽、语言、字号和合并选项变化重新计算高度，小窗口可滚动操作。
- KiCad 矩形统一直角，实心填充采用主体背景颜色；预览同步显示直角。中间层继续保留来源圆角，焊盘形状不变。
- KiCad 界面和合并流程与 AD 对齐：Lib 合并开关、独立的符号/封装库名、分别保留单器件副本、相同的 3D 目录规则。KiCad 没有追加模式，保留引脚电气类型配置和固定 KiCad 预览。
- AD 和 KiCad 普通导出、再次合并均以本次成功转换的选择覆盖同名库。例如 A、B 改选为 A、C 后，结果只有 A、C。KiCad `.pretty` 整体更新并移除旧成员；写入失败或取消时恢复原库。AD 显式追加仍保留原库成员。

旧统一 KiCad 库名迁移到符号和封装两个名称，旧合并选择继续保留。IR 协议仍为 1.0，字段含义和已有序列化兼容规则不变。

本地最新入口：`outputs/LCSC3D.exe`。EXE、源码包、使用说明和校验和同步到 `outputs/` 与 `outputs/v2.3.0-demo.3/`。未推送或发布线上 Release。
