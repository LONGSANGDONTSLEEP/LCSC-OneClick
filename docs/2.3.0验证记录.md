## 原生 EDA 验证范围

AD/KiCad 导出器、中间层和几何实现与已完成的 demo.4 验证相同；本次未修改这些模块。沿用 KiCad **8.0.9 / 9.0.9 / 10.0.7** 的 31 个器件、39 个符号单元、671 个引脚、29 个封装原生读写与几何检查，625 个焊盘对象中含过孔表示，72 个带孔对象，最大铜包围框偏差 0.001258 mm。

AD 采用独立二进制读取与合并/追加回归核对，不将本次自动化描述为 AD GUI 实机验证。KiCad 封装过孔以无编号镀通孔表示，网络归属需在 PCB 中核对。详细几何、日志故障注入和原生读取范围见 [demo.4 验证记录](2.3.0-demo.4验证记录.md) 与 [日志覆盖审查](日志覆盖审查.md)。
